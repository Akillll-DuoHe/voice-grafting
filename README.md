## 两个包

| 包 | 用途 | 当前插件版本 |
| --- | --- | --- |
| 通用声音包 `packages/voice` | 给已有 DSH/平台桥增加本地 ASR、TTS 和可选歌声转换、训练工具 | 0.3.0 |
| 独立 QQ 桥 `packages/qq-bridge` | 自备角色 QQ，通过 NapCat / OneBot 接 DSH；可再接通用声音包 | 0.8.0-offline.3 |

不包含虚拟形象和嘴型同步。其他人的平台桥可以接声音服务，但需要按其接口做适配；安装声音包不会自动改写每一种第三方桥。

## 开始维护

在本目录打开 PowerShell：

```powershell
.\维护.ps1 test
.\维护.ps1 check
.\维护.ps1 build-code
```

需要 Node 24.20 或更新版本，以及 Python 3.11 或更新版本。维护入口优先使用本机资源目录中已带的便携解释器；源码仓本身不依赖全局 npm 安装。`test` 只跑离线测试，不登录 QQ、不调用模型、不生成媒体。

`build-code` 只验证源码装包，不是完整离线包。真正的完整离线构建使用 `build-offline`，会从本地资源复制约数十 GB 的依赖和模型。此命令不会启动模型。详细步骤见版本维护文档。
