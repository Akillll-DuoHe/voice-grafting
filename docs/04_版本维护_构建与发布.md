# 版本维护、构建与发布

## 日常工作顺序

1. 在本仓开 `codex/` 分支，读 STATUS 与变更记录。
2. 共享逻辑改 `shared/`；平台特有逻辑改 `packages/qq-bridge`，声音逻辑改 `packages/voice`。
3. 运行 `.\维护.ps1 test`：同步共享副本，执行单元与桥离线集成测试。
4. 运行 `.\维护.ps1 check`：检查共享一致性、版本对应、Git 公开文件与本机私有匹配规则。
5. 运行 `.\维护.ps1 build-code`：生成不含模型/运行环境的代码装包，用于核对 TGZ 和结构。它不能发给用户当完整离线包。
6. 按改动做有授权的真实平台/模型验收，记录实际通过项目和未运行项目。
7. 提升对应组件版本，再构建新的完整离线候选，检查许可、隐私、校验值、安装和跨机路径。
8. 确认后归档新的 ZIP、SHA、版本说明与验证记录。原版本保持不可变。

## 共享模块

`scripts/sync-shared.mjs` 把共享源同步到两包。`--check` 只检查不写。记忆和点歌两包都需要；回复偏好目前由 QQ 桥使用。

测试入口使用真实桥代码，但以最小离线宿主替代 DSH SDK 与平台传输；不会对真实平台发消息。Node 内置 SQLite 需要足够新的 Node。

## 版本

```powershell
# 示例：下一版声音包
python scripts/set-version.py voice 0.3.1
.\维护.ps1 test
.\维护.ps1 check
```

脚本同时更新 VERSION.json、插件 package.json 与安装器内的 TGZ 文件名。它不自动宣布验收完成，也不覆盖已归档 ZIP。README 标题和发布说明仍需人工按新行为核对。

## 离线资源

`本地资源/assets.local.json` 指向两个干净的完整发行基线。其模型、引擎、依赖、便携解释器和许可供后续构建复用。公开源码库不跟踪数十 GB 资源；发布完整离线包时仍可把许可允许的资源带进去。

新机器只有源码时，需要自行准备这份资源库或取得已发布离线包，解压到本地资源并填写自己的索引。不要把作者的 `本机私有` 或旧运行现场当作构建输入。

资源基线包含历史 delivery-manifest.json。完整构建按该清单校验复制的资源，只允许 `runtime/models/engines/licenses`（声音）或 `runtime/third-party`（QQ桥）进入；插件 TGZ 从当前源码重新生成。不能把历史基线里的 user-data、日志、输出、旧 install 包或私人参考顺带复制。

## 构建命令

```powershell
.\维护.ps1 build-code
# 数十 GB，先确认空间；只拷贝/装包，不加载模型
.\维护.ps1 build-offline
# 只构建一个组件，Python 入口还支持生成 ZIP64
python scripts/build.py --component voice --zip
```

输出在被忽略的 `构建产物/<时间>/`。无 `--code-only` 时要求本机资源索引存在；`--zip` 才压 ZIP64 和 SHA。候选包的 BUILD-VALIDATION.json 明确说明它是否完整离线包；历史 VALIDATION.json 仅代表原基线，不能借用为新改动的验收结果。

源码构建不需要 npm 拉包；TGZ 按 package.json 的 files 白名单生成。便携依赖更新是另一项维护工作：从上游取得固定版本、记录哈希/来源/许可，按正确 Python 环境安装并重新做离线导入和路径检查，不能复用作者机器的绝对路径或复制未知环境。

## 发布前检查

- 新 TGZ 版本、文件名、安装器、VERSION.json 一致。DSH/pnpm 可能缓存同版本包，不用同名覆盖代替升级。
- 新 profile 的真实 DSH 安装与 schema 加载；端口冲突、token、existing-config 保护；不能用空配置导入代替运行验收。
- 本地服务、平台语音编码、ASR、当前回复合成、模式保持、歌单轮换、记忆换会话按改动复测。
- ZIP 的 CRC、逐文件 SHA 清单、模型固定版本和许可核对；隐私扫描不输出任何密钥。
- Git 只跟踪公开文件，构建/发行目录是独立附件。许可证跟随二进制一起提供。
- 当前没有配置远端；用户确认发布目标后再设置 remote、推送、确认实际网址。

不要用 Git 忽略代替审查：`git add -f` 或手工上传整个文件夹都会绕过它。不要把今天的已有 ZIP 因目录搬迁重新压缩或改内容。
