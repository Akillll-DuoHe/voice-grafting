# 用自己的声音转换并收录歌曲

需要两个输入：你选定的单人说话参考 WAV；你自己提供的演唱干声 WAV。干声决定歌词、旋律、节奏，模型转换音色，不是通过听歌永久训练“学会这首歌”。先用稳定、中低音、无男声混唱的段落试；高音超出参考材料时仍可能破音或出现机械感。

本包不附歌曲、原唱、伴奏、训练成品，也不联网搜歌。混音视频请先用你已有的工具提取并分离人声；本包此入口接收干声 WAV，不把读歌词当唱歌。
```powershell
.\runtime\node\node.exe .\tools\cli.mjs convert --source "你的演唱干声.wav" --reference "你的说话参考.wav" --out "新的转换成品.wav" --device cuda
```
使用原版Vevo2权重、32步、零变调；18秒分块、0.5秒重叠，逐组件使用GPU。只运行这一模型，不会关闭别人的模型。显存不足应自己安排空闲时运行或使用 --device cpu；不会自动卸载其它服务。

先在播放器里试听并标好想留的区间。自己的JSON清单示例：
```json
[{"id":"clip01","song":"song01","title":"我的第一首歌","file":"转换成品.wav","start":20,"end":45,"aliases":["第1首"]}]
```
原始文件相对于该JSON所在目录解析。一次清单可以包含多首、多段。确定已试听后，使用声音包自带Python把它收录到QQ桥自己的数据目录：
```powershell
.\runtime\python311\python.exe -I .\tools\register-songs.py --data "QQ桥的数据目录" --manifest "你的已选片段.json" --reference "你的参考.wav" --approve
```
只截清单区间并生成MP3，原素材不删除。配套QQ桥可以说“歌单”“唱歌名”“唱song01”“换一首”“唱个别的”“唱长的”“唱短的”。长段>=30秒、短段<30秒；先轮换歌曲，再轮换同一首中的片段；发送确认后才更新游标。只播已批准的片段，未知歌曲或无匹配长度会明确说明，不回退到原唱、完整歌或临时TTS。
