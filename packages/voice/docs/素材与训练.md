# 自己准备声音并训练

## 先做参考克隆

提供自己的或获授权的单人干净 WAV，建议5—15秒（可用范围按引擎检查），自然说话、无背景音乐、无混响、无别人插话、无削波。保留原采样率；不要以变调或过量降噪掩盖问题。参考文字必须对应实际录音。先固定一条参考，用同一批中/日/英测试句试听，选定后锁定文件SHA，避免后续换成另一条。

参考克隆不会训练出新的权重。默认 VoxCPM2 可用说话参考直接生成；Qwen Base 备选可用带转写的参考，没转写则采用 x-vector 模式，效果需自己听。
```powershell
.\runtime\node\node.exe .\tools\cli.mjs qwen --reference "你的参考.wav" --reference-text "录音中的原话" --text "新的测试句" --language Chinese --out "新的试听.wav"
```

## 真正的 LoRA 微调

建议先收集同一说话人20—60分钟以上质量一致的素材作为起点，这不是官方最低时长保证。剪成3—30秒PCM WAV；每条人工核对转写，给原录音分组，同一原录音的相邻切片不要跨训练/验证集。不同人物各自建数据集，不能混在一个身份里。嬉笑、叹气等要有真实对应素材和准确标注，不能只靠给普通文字加情绪词保证效果。

按 plugin/training-guides/materials.example.csv 提供 audio,text,speaker,group,split。运行：
```powershell
.\runtime\node\node.exe .\tools\cli.mjs prepare-training --metadata "你的metadata.csv" --speaker my_voice --out "新的数据集目录"
```
它会检查时长、说话人标签、重复PCM和分组隔离，生成train/val JSONL；不负责自动辨别人声身份，也不等于完成训练。

复制 plugin/training-guides/voxcpm2-lora.example.yaml 到自己的目录，填写包内 models/voxcpm2 的绝对路径、train/val清单、输出目录。先小批量确认，不覆盖官方基础模型：
```powershell
.\runtime\node\node.exe .\tools\cli.mjs train --config "你审核过的训练.yaml"
```
这会调用包内官方 VoxCPM 训练脚本，依赖已附。显存需求取决于模型、精度、序列长度和训练设置；推理可运行不代表完整训练能在同一显卡运行，低显存请从 batch_size=1、较短片段和LoRA开始并检查真实峰值。此整包没有替安装者完成训练或保证收敛。

训练后保留完整检查点目录（包括 lora_config.json 和权重），填入自己的 backend.local.json 的 lora_weights_path，再只重启自己的声音后端；基础权重和原参考不覆盖。用固定留出句对比清晰度、身份、噪声、长句和情绪，再决定采用哪个检查点。

Vevo2 用于原版权重的参考转换；因其权重许可含 ND，不把修改后的 Vevo2 权重作为可自由分发成果。本包的训练路径选 VoxCPM2。所有个人参考、数据集和训练检查点都应留在自己的数据目录，不提交公共仓库。
