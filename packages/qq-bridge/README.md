# DSH 独立 QQ 桥 · 离线版 0.8.0

适用于要从头连接普通角色QQ与DSH的人。包含原生DSH会话桥、持续文字/语音与中日文模式控制、已批准片段点歌与换歌、本地长期记忆和上下文预算。声音引擎使用另一个独立的“通用本地声音层”包；此包不重复附十几GB模型，也不强迫已有桥用户换桥。

## 安装顺序

1. 准备自己的 DSH 和可聊天的模型；QQ客户端从腾讯官方安装。普通 QQ 客户端、DSH 主程序、显卡驱动不在本包中转分发。
2. 准备两个不同QQ号：角色专用号负责登录，本人聊天号用于白名单。注册和验证码由本人完成，不能把自己的主号误当角色号扫码。
3. 如需声音，先安装通用声音包并生成自己的 voice.local.json。
4. 双击本包 `安装配置.cmd`，填写自己的两个QQ号、声音配置路径（可留空先文字）、DSH CLI路径。脚本只用包内Node和插件，不联网安装依赖。
5. 按 docs/QQ登录与连接.md 启动包内原版NapCat Framework并在本机确认角色登录，导入自己生成的OneBot配置。
6. 从本人号给角色号发普通文字、语音，再测试“用语音回复”“打字回复”“用日语加语音”。模式分别持久化，直到你明确改动。

命令行：
```powershell
.\runtime\node\node.exe .\tools\cli.mjs setup --bot 你的角色QQ --owner 你的本人QQ --voice-config "你的voice.local.json" --data "你的桥数据目录"
.\runtime\node\node.exe .\tools\cli.mjs install --dsh "你的dsh.cmd" --profile desktop --data "你的桥数据目录"
```
不接声音时 setup 加 --text-only。空白名单拒收全部私聊，默认不接群聊。保持原DSH模型、人设与账号配置，由你自己写角色规则；包内没有作者的性格、固定称呼、聊天偏好、模型凭据、歌曲或训练数据。

记忆见 docs/本地记忆.md。歌曲导入见通用声音包 docs/歌声转换与歌单.md；没有自己的批准歌单时，不能把文字朗读当成已完成演唱。开机后先启动DSH与角色QQ；语音后端由已配置的声音插件管理。
